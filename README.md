# Distributed Key-Value Store

A Java-based distributed key-value store designed to explore
consensus, replication, fault tolerance, and distributed systems.

## Planned Features

- Key-value operations: PUT, GET, DELETE
- TCP-based client-server communication
- Raft leader election
- Log replication and commitment
- Fault-tolerance testing
- Performance benchmarking

## Technology Stack

- Java 21
- Maven
- Git and GitHub
- JUnit 5

Under development.
